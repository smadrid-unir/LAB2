Actividad 2: Tutorial de una tecnología/framework

Justificación del framework

¿Para qué sirve?

Angular es un framework de desarrollo web creado por Google que sirve para construir aplicaciones web de manera estructurada. El objetivo de Angular es facilitar la creación de interfaces dinámicas e interactivas mediante un conjunto de herramientas integradas que organizan el código, la comunicación con servidores, la gestión del estado y el manejo eficiente del HTML.

Además, Angular resuelve otros problemas en el desarrollo de interfaces modernas, como la separación de funcionalidades, la sincronización de datos entre la vista y la lógica, y la modularidad del software. Es un entorno robusto, preparado para equipos grandes, proyectos escalables y aplicaciones que deben mantenerse durante años con calidad y consistencia.

¿Qué aplicaciones tiene?

Se utiliza ampliamente en la creación de aplicaciones empresariales, plataformas de administración, sistemas CRM, dashboards, herramientas internas corporativas y aplicaciones web que requieren gran volumen de datos y funcionamiento en tiempo real. Su arquitectura se basa en componentes permite construir módulos reutilizables y ampliables, lo cual es ideal para desarrolladores que buscan estandarizar su desarrollo web.

También se utiliza para crear aplicaciones multiplataforma mediante frameworks complementarios como Ionic, portales de comercio electrónico, sitios educativos y aplicaciones públicas que necesitan rendimiento, accesibilidad y un código fácil de mantener. Gracias a su ecosistema, Angular es apto tanto para proyectos pequeños como para soluciones de gran escala.

¿Sobre qué lenguajes se apoya?

Angular se apoya principalmente en TypeScript, un superconjunto de JavaScript que añade tipado estático y características avanzadas al lenguaje. TypeScript permite escribir código más robusto y fácil de mantener, ya que facilita la detección temprana de errores durante el desarrollo.

Además de TypeScript, Angular utiliza HTML para la estructura de las vistas y CSS para el diseño y la presentación visual de las aplicaciones. También se apoya en JavaScript para ciertas funcionalidades y en RxJS (Reactive Extensions for JavaScript) para manejar programación reactiva y flujos de datos asíncronos.

¿Qué prerrequisitos necesita?

Es necesario tener conocimientos básicos de HTML, CSS y JavaScript, ya que estos son los fundamentos sobre los cuales se construyen las aplicaciones Angular. Además, es recomendable tener una comprensión básica de TypeScript, ya que Angular está escrito en este lenguaje y su uso es fundamental para aprovechar todas las características del framework.

También es útil tener experiencia con conceptos de programación orientada a objetos, manejo de módulos y componentes, así como familiaridad con herramientas de desarrollo web como Node.js y npm (Node Package Manager), que se utilizan para gestionar las dependencias y ejecutar scripts de desarrollo en proyectos Angular.

Instalación

¿Se precisa instalación?

Sí, para trabajar con Angular es necesario instalar ciertas herramientas y dependencias en tu entorno de desarrollo. La instalación básica incluye Node.js, npm (Node Package Manager) y el Angular CLI (Command Line Interface), que facilita la creación y gestión de proyectos Angular.

¿Qué pasos hay que realizar para realizar la instalación?

1. Instalar Node.js: Descargar Node.js desde su sitio web oficial (https://nodejs.org/). Esto también instalará npm, que es el gestor de paquetes necesario para Angular.

2. Instalar Angular CLI: En una terminal o línea de comandos, se ejecuta el siguiente comando para instalar Angular CLI en el sistema:

npm install -g @angular/cli

3. Crear un nuevo proyecto Angular: Una vez que Angular CLI está instalado, se crea un nuevo proyecto ejecutando el siguiente comando en la terminal, durante la creación, se responden una serie de preguntas sobre la configuración del proyecto:

ng new nombre-del-proyecto

4. Navegar al directorio del proyecto: Si no lo estamos ya, debemos dirigirnos al directorio del proyecto con el comando:

cd nombre-del-proyecto

5. Iniciar el servidor de desarrollo: Finalmente, se inicia el servidor local de desarrollo con el comando:

ng serve

Esto iniciará la aplicación y se accede a ella mediante el navegador web en la dirección http://localhost:4200/.

¿Versiones necesarias?

Para trabajar con Angular, es recomendable utilizar las versiones más recientes de Node.js y Angular CLI para poder tener acceso a las últimas características y mejoras de seguridad. Se recomienda utilizar al menos Node.js versión 14.x o superior y Angular CLI versión 15.x o superior.

¿Rutas para tener en cuenta?

Al instalar Angular CLI globalmente, se agrega a la variable de entorno PATH en el sistema, lo que permite ejecutar comandos de Angular desde cualquier ubicación en la terminal. La ruta donde se instala npm globalmente esté incluida en el PATH.

¿Variables de entorno?

No es necesario configurar variables de entorno específicas para Angular. Sin embargo, algunas herramientas adicionales o configuraciones personalizadas, podrían necesitar establecer variables de entorno relacionadas con Node.js o npm. La variable PATH debe incluir la ruta a los binarios de Node.js y npm para que se puedan ejecutar los comandos desde la terminal sin problemas.

¿Necesita base de datos?

Angular en sí mismo no requiere una base de datos para funcionar, ya que es un framework de frontend que se ejecuta en el navegador del cliente. Sin embargo, es posible crear aplicaciones Angular que interactúan con bases de datos a través de APIs o servicios backend para almacenar y recuperar datos.

Si la aplicación Angular necesita persistir datos, habrá que configurar un backend que maneje la lógica de la base de datos. Se pueden utilizar diversas tecnologías para el backend, como Node.js con Express, Django, Ruby on Rails, entre otros, y conectar la aplicación Angular a través de HTTP utilizando servicios RESTful o GraphQL.

Utilización del framework

¿Cómo empezar a crear una aplicación base?

Para comenzar a crear una aplicación base en Angular, como he explicado anteriormente, se parte de la estructura generada por Angular CLI. Desde ahí, se pueden crear nuevos componentes con el comando ng generate component nombre-componente y organizar la lógica en servicios y módulos. Es importante mantener el código limpio y modular, aprovechando las ventajas de TypeScript y la arquitectura basada en componentes.

¿Cómo visualizar los resultados de la ejecución?

Para ver los resultados, se ejecuta ng serve y se visualiza el progreso en el navegador en http://localhost:4200/. Angular recarga automáticamente la página cada vez que guardes cambios, lo que facilita mucho el desarrollo y la prueba de nuevas funcionalidades.

Explicación del funcionamiento del framework

¿Actúa sobre páginas, ficheros, secciones…?

Angular actúa principalmente sobre componentes, que son bloques independientes de funcionalidad y vista. Cada componente tiene su propio archivo HTML, CSS y TypeScript, lo que permite dividir la aplicación en secciones lógicas y reutilizables. Además, Angular gestiona el enrutamiento entre páginas y la comunicación entre componentes de forma eficiente.

¿Cómo se editan/modifican los ficheros que actúan en el framework?

Los ficheros se editan directamente desde el editor de código, como Visual Studio Code. Se pueden modificar los archivos de componentes, servicios y módulos para adaptar la aplicación. Angular detecta los cambios y recompila automáticamente el proyecto, mostrando los resultados en tiempo real.

¿Cómo se referencian los ficheros creados desde otras aplicaciones (si es el caso)?

En Angular, los ficheros se referencian mediante importaciones de módulos y componentes. Para integrar Angular con otras aplicaciones, se pueden exponer servicios a través de APIs REST o GraphQL, o incluso incrustar la aplicación Angular en otras plataformas mediante web components o iframes, según el caso.
